# Dreamhouse Stays

ASP.NET Web Forms property rental site for browsing, buying, editing, and publishing rental properties.

## Run Locally

1. Run `RunLocalhost.bat` or the executable file "DreamHouseLauncher.exe.
2. It will launch the webpage `http://localhost:58457/` automatically.
3. The SQLite database is stored at `App_Data/Dreamhouse.db`.

## Notes

- Buyer accounts can search and buy/enquire properties.
- Seller accounts can publish new properties and edit existing property details.
- This project targets .NET Framework 4.8 and uses IIS Express for local hosting.
